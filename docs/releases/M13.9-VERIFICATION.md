## Release hygiene rule

The packaged artifact must contain no `vendor`, `node_modules`, package caches, font binaries, real `.env`, provider keys or bearer tokens. A control archive is fresh-extracted and subjected to the same available source gate before the final ZIP is built. The final ZIP is then extracted once more and subjected to the available gate; the external `.sha256` sidecar is authoritative for the delivered artifact.
