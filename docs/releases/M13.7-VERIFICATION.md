- deterministic `ai-default` offer at the requested amount;
- page sections bound to the generated course;
- optional media provider failures becoming truthful `skipped` states;
- trainer ownership isolation;

## Environment-dependent gates

These probes are intentionally not reported as PASS in this runtime:

### Pest / Laravel / PostgreSQL migrate:fresh — BLOCKED

`vendor/autoload.php` is absent by release policy and Composer is unavailable in this runtime. `php artisan test --filter=OneBriefCourseCreationTest` exits before Laravel boot with status 255.

### npm / Vite / Prettier / ESLint full dependency-backed gate — BLOCKED

An `npm ci --prefer-offline` attempt could not complete because registry fetches repeatedly returned `EAI_AGAIN`, including `zod`, `zod-validation-error`, `yargs` and related tarballs. The partial `node_modules` directory was removed before packaging.

The source-level TypeScript/TSX syntax gate therefore uses the globally installed TypeScript parser and reports zero parse diagnostics, but this is not represented as a full dependency-backed typecheck/build.

### Docker production image — BLOCKED locally

Docker is not installed in this runtime.

## Release hygiene

The packaged release must not contain `vendor`, `node_modules`, npm/pnpm caches, font binaries, real `.env` files, credentials, API keys or bearer tokens. The final artifact is additionally re-extracted and subjected to the same available gate after packaging; the external `.sha256` sidecar is authoritative for the delivered ZIP.
