# M13.7 — AI Course Creation Engine / One‑Brief‑to‑Course

Version: **1.1.8**  
Date: **2026-09-01**

## Purpose

M13.7 turns the canonical Course Domain delivered in M13.6 into the primary creator-facing AI workflow: one brief creates a complete Academy draft without requiring the trainer to manually chain separate AI capabilities.

## Flow

```text
Brief
  ↓
blueprint
  ↓
materialize draft
  ↓
cover (optional)
  ↓
thumbnail (optional)
  ↓
narrations (optional, one lesson/request)
  ↓
M10 default offer
  ↓
M11 landing draft (optional)
  ↓
review
```

The run is persisted in `course_creation_runs`. Reloading the page does not erase progress. Fatal essential-step failures can be resumed from the same step.

## Existing systems reused

- M07 `AcademyAiRunner` and `course.generate`
- M07/M11 `ApplyAcademyAiRunAction`
- M13.6 `CourseMediaGenerationService`
- M10 `CourseOffer`
- M11 `page.generate` and Page Builder
- M09 `IndexCourseKnowledge`
- existing Course Builder for final human review

No second pricing engine, page engine, RAG indexer or course model was introduced.

## Safety

- generated courses stay `draft`;
- generated pages stay `draft`;
- M13.7 never calls `PublishCourseAction`;
- no Stripe Product/Price is provisioned during generation;
- optional media/page failures are explicit `skipped` states rather than fabricated outputs;
- trainer ownership is enforced on run, course and page access;
- the existing publish lifecycle and M08 approvals remain authoritative.

## Thinking Orb

The Orb is deliberately a secondary status surface. It maps to real persisted stages:

- `shaping` — blueprint
- `weaving` — materialize
- `composing` — cover/thumbnail
- `listening` — narrations
- `connecting` — offer
- `solving` — landing
- `breathing` — review

Reduced-motion users receive a non-animated state.

## Scope intentionally deferred

M13.7 does not add quizzes, assignments, certificates, drip scheduling, a LessonBlock system, or a multi-agent runtime. Those remain separate product decisions and should only be introduced when the Course Studio needs them.
