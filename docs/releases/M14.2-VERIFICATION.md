## Historical-data hardening found during release review

Before packaging, hostile review found that curriculum parent deletion could otherwise cascade into M14.1/M14.2 learning history. M14.2 therefore uses restrictive Module/Lesson foreign keys for assignments and includes an upgrade migration that converts M14.1 assessment parent foreign keys to `RESTRICT`.

This preserves assessment attempts and assignment submissions instead of silently deleting them when curriculum structure changes.

## Packaging rule

The control archive is created without `vendor`, `node_modules`, npm caches, font binaries, real `.env` files or secrets. It is extracted into a fresh directory and gated. That evidence is embedded here, then the final ZIP is rebuilt, SHA-256 is generated and the final artifact is extracted/gated a second time.
