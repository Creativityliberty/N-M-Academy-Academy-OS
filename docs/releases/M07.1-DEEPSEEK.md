# M07.1 — DeepSeek Provider

Release: **NÜM Academy OS v0.7.1**

M07.1 adds DeepSeek as a first-class Academy AI engine behind the existing `AiProvider` abstraction.

Supported defaults:

- `deepseek-v4-pro` for high-quality creator and reasoning workloads;
- `deepseek-v4-flash` as a lower-cost/faster option by configuration;
- `deepseek-v4-flash-vision-exp` remains available through model override for experiments, but M07.1 Academy capabilities are text-first.

DeepSeek uses `https://api.deepseek.com/responses` with JSON Schema structured output and configurable reasoning effort.

No new Coolify service or package dependency is introduced.
