# M13.6 Verification

## Scope

M13.6 extends the existing Academy course domain and adds granular Creator/Tower course-creation CRUD without introducing a second LMS, second commerce engine, or LessonBlock rewrite.

## TDD evidence

`tests/Contract/M13_6CanonicalCourseDomainContractTest.php` was expanded before each production layer and observed RED on the missing behavior. The observed RED sequence included:

1. missing canonical course-domain migration;
2. missing AI `level` / positioning schema support;
3. missing `categories.list` discovery;
4. missing media provider contracts;
5. CI not yet executing M13.6;
6. Trainer course update still mutating the legacy Stripe catalog;
7. missing canonical Trainer request/resource/form serialization;
8. public course pricing not consistently CourseOffer-aware;
9. missing Course Studio media controller/routes/UI;
10. AI narration replacing `text` lesson type with `audio`;
11. new offer tools not classified as financial;
12. MCP lesson mutations not normalizing incompatible media references;
13. `offers.update` not yet requiring SENSITIVE approval.

Each contract failure was corrected before the final available source gate.

A Laravel feature test was also added at `tests/Feature/Trainer/CanonicalCourseDomainTest.php` for canonical persistence, Academy AI materialization, MCP curriculum creation and OpenAI media service behavior. It is included for CI but could not execute locally because this source release deliberately does not contain `vendor/`.

## Packaging policy

The final ZIP must contain the complete cumulative M01→M13.6 source and must not contain:

- `vendor/`;
- `node_modules/`;
- npm/pnpm caches;
- font binaries;
- real `.env` files;
- credentials or API secrets.
