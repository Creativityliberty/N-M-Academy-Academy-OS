# M13.8 — Mission Tower Chat UX + Rich Response Renderer

Version: **1.1.9**  
Date: **2026-09-01**

M13.8 upgrades only the Mission Tower conversation presentation layer. The existing Academy shell, Tower navigation, routes, Durable Memory, Mission Compiler, MCP governance, Approvals, Evidence, Course Creation and M13.7 Thinking Orbs remain intact.

## Rich assistant responses

Tower assistant messages now render a safe Markdown subset without `dangerouslySetInnerHTML` and without adding a new runtime dependency. Supported presentation includes headings, bold, italic, strikethrough, inline code, fenced code blocks, blockquotes, ordered/unordered/task lists, links and responsive tables.

External links are scheme-filtered. Raw HTML is never interpreted. Code blocks include copy controls and lightweight token highlighting.

## Structured execution cards

The chat DTO now exposes the already-existing mission execution context to the frontend:

- mission steps/tools and risk/status;
- mission/run linkage;
- inline governed Approval card;
- up to four recent Evidence records plus total evidence count.

No second mission/evidence store is introduced.

## Chat ergonomics

- assistant responses use editorial full-width layout instead of a large chatbot bubble;
- user messages remain compact bubbles;
- sticky composer with Cmd/Ctrl+Enter shortcut;
- truthful Tower Activity Orb while the existing synchronous request is in flight;
- Copy and Retry actions on assistant messages;
- intelligent conversation auto-scroll that stops forcing the viewport when the user scrolls upward;
- execution tool cards are collapsible.

M13.8 intentionally does **not** pretend to stream server state or provide a fake “Stop mission” control. The current Tower Chat request lifecycle is synchronous; aborting the browser request would not prove that an already-started governed action was cancelled server-side.

## AI formatting guidance

Direct answers and post-mission grounded summaries are instructed to use clean Markdown when it improves clarity and to avoid raw JSON unless explicitly requested.

## Scope guard

M13.8 does not modify Course Domain, CourseCreationRun, Sales, Page Builder, Tutor/RAG, Mission Runner semantics, Approval semantics, Evidence semantics, Durable Memory or Tower navigation.
