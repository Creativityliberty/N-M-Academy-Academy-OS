## Local dependency-backed probes

The packaging runtime intentionally contains no `vendor/`, no `node_modules/`, and no Docker binary. Fresh probes therefore stop before the application tests/build can execute:

```text
php artisan test --filter=MissionTowerMemoryTest
BLOCKED (exit 255)
→ vendor/autoload.php absent

npm run build:ssr
BLOCKED (exit 127)
→ vite executable absent because node_modules is not packaged

docker compose -f docker-compose.coolify.yml config
BLOCKED (exit 127)
→ docker command unavailable in this runtime
```

An attempted dependency installation also cannot reach the npm registry from this runtime (`getaddrinfo EAI_AGAIN registry.npmjs.org`), so these dependency-backed gates are deliberately delegated to the real CI/Coolify-capable environment rather than misreported as local PASS.

## Release extraction rule

The final ZIP must be extracted into a fresh directory and the source gate above rerun on that extracted copy before the release is reported as final.
