# M13.5.1 — Course + Release Hardening

## Goal
Harden the existing NÜM Academy OS v1.1.5 course, commerce, media, AI, MCP and Tower mutation paths before expanding the Course Domain in M13.6.

## Invariants
- Preserve the current Course → Module → Lesson core; no rewrite.
- Preserve CourseOffer as the modern commerce layer and never delete financial history through the normal course delete UX.
- Preserve Proposal → Apply for Academy AI and governed MCP approvals.
- Any course content mutation path must leave Tutor/RAG refreshable through one domain-level indexing trigger.
- Publishing must use one canonical action so status and published_at cannot diverge.
- Media replacement must not leave stale audio/PDF/video references.
- Existing release packaging rules remain mandatory: cumulative ZIP, SHA-256, fresh extraction retest, no vendor/node_modules/fonts/real .env/secrets.

## Scope
1. Fix M13.3 migration ordering for fresh PostgreSQL installs.
2. Archive courses instead of physical deletion through trainer/admin CRUD.
3. Fix audio/PDF files being lost when a new lesson is added during course update.
4. Clean stale lesson media when the lesson type changes.
5. Add page.generate/page.optimize to request validation and require page_id for optimize.
6. Fix dotted MCP receipt metadata lookup in Tower approvals.
7. Centralize course publish/unpublish semantics, including published_at.
8. Remove public runtime mock fallbacks for course detail.
9. Ensure MCP lesson mutations queue course knowledge re-indexing after commit.
10. Add source contract and Laravel regression coverage for the above.

## Deferred to M13.6
Canonical positioning fields, target audience persistence, text lesson type, cover/thumbnail generation, AI image/TTS, expanded module/lesson CRUD, canonical CourseOffer pricing in all surfaces.
