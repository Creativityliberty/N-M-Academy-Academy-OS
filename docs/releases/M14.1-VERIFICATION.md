## Regression fixed during release QA

The gate exposed an inherited M13.9 migration ordering problem: `course_review_proposals.course_creation_run_id` referenced `course_creation_runs` before that table existed on a fresh install. A RED M14.1 contract assertion was added, then the migration was moved after `course_creation_runs` with an upgrade-safe legacy guard. The migration-order gate then returned zero forward FK issues.

## Packaging rule

The final archive must contain no `vendor`, `node_modules`, npm cache, font files, real `.env`, or provider credentials. A control ZIP is extracted and gated first; verification evidence is then embedded, a final ZIP is rebuilt, SHA-256 is generated, and the final archive is extracted and gated again.
