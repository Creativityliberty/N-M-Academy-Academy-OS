# M14.1 — Quiz & Assessment Engine

Version: **1.3.0**  
Date: **2026-09-01**

## Purpose

M14.1 adds durable authored quizzes and assessments to the existing Course → Module → Lesson domain without introducing LessonBlock and without changing M09 Tutor quiz semantics.

## Domain

- `CourseAssessment`: authored quiz/assessment attached to a course and optionally a module/lesson.
- `CourseAssessmentQuestion`: `single_choice`, `multiple_choice`, or `true_false`.
- `CourseAssessmentOption`: option text plus server-only correctness.
- `CourseAssessmentAttempt`: persisted student attempt, score and pass/fail result.
- `CourseAssessmentAnswer`: persisted selected option ids and awarded points.

M09 `TutorQuizSession` remains a separate RAG study-aid subsystem.

## Scoring and attempt safety

`AssessmentScoringService` is the only grading boundary. Multiple-choice uses exact-set matching, there is no negative marking, pass/fail is derived from `passing_score_percent`, and `max_attempts` is enforced server-side with transactional attempt numbering.

Correct answers are not included in the student pre-submit payload. Explanations are exposed only after submission and only when enabled by the trainer.

To preserve historical results, the question bank becomes immutable after the first persisted attempt. Assessments with attempts cannot be deleted and question create/update/delete/reorder operations are rejected once history exists.

## Trainer experience

A course-local workspace is available under the trainer course routes for:

- assessment list/create/update/delete;
- pass score / max attempts / shuffle / explanation settings;
- question and option authoring;
- Academy AI generation through `assessment.generate` proposal → Apply.

The existing Course Builder is not rewritten; it receives a focused Quiz & Assessments entry point.

## Student experience

Students can open accessible assessments from the course experience. Enrollment and module access continue to use the existing `CourseOffer.access_rank → Enrollment.access_rank → Module.minimum_access_rank` chain.

The student player shows question count, pass score, remaining attempts, persisted result and optional explanations. Assessment results do not yet gate lesson/course completion; that belongs to M14.3.

## Academy AI / One-Brief

New capability: `assessment.generate`.

AI output is schema-validated before Apply. One-Brief-to-Course can enable `generate_assessments`; the `assessments` step generates one module assessment per `advance()` call to preserve resumability and bounded latency. Provider failure on this optional stage can be skipped rather than failing the entire course creation run.

## Academy MCP / Mission Tower

New governed tools:

- `assessments.list`
- `assessments.get`
- `assessments.create`
- `assessments.update`
- `assessments.delete`
- `assessment.questions.create`
- `assessment.questions.update`
- `assessment.questions.delete`
- `assessment.questions.reorder`

Mutations are WRITE. Mission Tower still uses the Academy MCP bridge and receives no direct CourseAssessment coupling.

## Review Center

M13.9 Course Review Center now displays the authored assessment count and links to the course assessment workspace. Absence of assessments does not block publication in M14.1.

## Migration hardening included

Final release QA discovered a real fresh-install ordering defect inherited from M13.9: the original `course_review_proposals` migration sorted before the M13.7 `course_creation_runs` table that it references.

M14.1 renames the review migration to `2026_09_01_030100_create_course_review_proposals_table.php`, after `2026_09_01_030000_create_course_creation_runs_table.php`, and includes a legacy migration guard. Existing Academies that already applied the M13.9 migration do not recreate the table, while fresh installs receive the correct FK order.

## Explicitly deferred

M14.1 does not add:

- open/free-text grading;
- assignments/projects or file submissions;
- completion requirements based on assessment pass status;
- certificates.

Those remain M14.2 and M14.3.
