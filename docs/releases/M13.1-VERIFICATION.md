## Manual governed-flow smoke test

1. Configure a Tower MCP token with at least one READ and one WRITE ability.
2. Open `/tower/missions`.
3. Create a mission containing READ → WRITE.
4. Run it.
5. Verify the READ step succeeds and Evidence contains its receipt.
6. Verify the WRITE step pauses and appears in `/tower/approvals`.
7. Approve it.
8. Verify the same run resumes, the WRITE step succeeds and the mission completes.
9. For a SENSITIVE tool, verify the exact phrase is required before approval.
