# M13.2 — Academy Observatory

NÜM Mission Tower now observes the Academy through the production Academy MCP gateway instead of bypassing domain boundaries with direct SQL reads.

## Sources

Every observation attempts these read-only MCP capabilities:

- `academy.summary`
- `sales.summary`
- `analytics.summary`
- `analytics.learning`
- `students.risk.summary`
- `community.posts.list`
- `events.list`
- `ai.usage.summary`

The Observatory persists normalized metrics and source status, not Community post bodies or author identities. A failed source creates a `partial` snapshot; rules for that unavailable domain do not silently resolve existing insights.

## Signal rules

M13.2 derives deterministic signals for:

- elevated refund rate;
- conversion drop versus the previous valid snapshot value;
- students at risk of not starting or becoming inactive;
- under-filled events starting within seven days;
- silent/empty Community activity;
- Tutor AI estimated cost spike over the previous 24-hour window.

Thresholds are controlled by environment variables and do not require an LLM. AI can enrich/prioritize later, but it is not the source of truth for whether a threshold was crossed.

## Insight lifecycle

Insights are de-duplicated by `(owner_id, fingerprint)`. Repeated observations update the same signal. If a governed mission has already been created, `mission_created` remains active while the anomaly persists. Once an observed domain becomes healthy, both `open` and `mission_created` signals can become `resolved`.

Mission creation is transactionally guarded with `lockForUpdate()` so concurrent clicks cannot create duplicate missions from the same insight.

## Student privacy

`students.risk.summary` returns aggregate counts only. Academy-level totals use unique student IDs so one learner enrolled in several courses is not counted multiple times in the global risk rate. Course-level rows remain available for diagnosis without names or email addresses.

## AI cost scope

The current cost field is explicitly `tutor_only`: Tutor runs persist token/cost estimates today, while Creator AI run records do not yet have equivalent normalized cost fields. The UI therefore labels this metric as Tutor cost rather than pretending it covers every Academy AI workload.

## Scheduler

```bash
php artisan tower:observe
```

Laravel schedules this command every 15 minutes with `withoutOverlapping()`.

For a manual capture from the Tower UI, use **Observer maintenant** on `/tower/insights`.

## Recommended environment

```env
TOWER_OBSERVATORY_ENABLED=true
TOWER_OBSERVATORY_REFUND_RATE_WARN=5
TOWER_OBSERVATORY_CONVERSION_DROP_PCT=15
TOWER_OBSERVATORY_LEARNING_RISK_PCT=25
TOWER_OBSERVATORY_EVENT_FILL_WARN=30
TOWER_OBSERVATORY_COMMUNITY_SILENCE_HOURS=72
TOWER_OBSERVATORY_AI_COST_SPIKE_PCT=50
TOWER_OBSERVATORY_AI_COST_MIN_BASELINE_CENTS=100
```

The Tower MCP token must include the read tools listed above. No new container or external datastore is introduced.
