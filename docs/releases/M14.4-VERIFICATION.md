# M14.4 — Verification Record

**Release:** NÜM Academy OS v1.5.1 — M14.4 Learning Experience + Factory Integration  
**Date:** 2026-09-02

## Verification policy

M14.4 is considered release-ready only after the cumulative source contracts and all dependency-independent gates pass on source, on a fresh extraction of a control archive, and again on the exact final archive. Checks that cannot execute without Composer dependencies, Node 24 registry access or Docker remain explicitly BLOCKED.

## TDD / integration hardening

The M14.4 contract was first observed RED because the Factory had no canonical capability registry for M14 learning features.

During integration QA, a second RED exposed an important behavioral gap: disabling Assessments or Assignments in Factory guarded their dedicated routes but the Student Course Player still serialized their references. The Course Player backend now checks the Academy feature switches before querying/serializing those primitives.

The milestone also verifies that:

- visual templates and capability profiles remain separate concepts;
- `certificates → completion`, `tower → mcp`, and `tutor → ai` dependencies are normalized;
- Student certificate navigation is feature-aware;
- authenticated certificate PDF download checks certificate ownership;
- public certificate actions respect white-label Academy defaults;
- Trainer M14 routes and Course Studio actions are capability-gated;
- the private `academy-assignments` Coolify mount is retained;
- Mission Tower remains French-by-default;
- direct `certificates.issue` remains absent from Academy MCP.

## Archive procedure

1. create a control ZIP from the frozen source under the v1.5.1/M14.4 root name;
2. verify ZIP integrity and SHA-256;
3. extract to a fresh directory and rerun the complete dependency-independent gate;
4. embed this verification record and release documentation;
5. build the exact final archive and SHA sidecar;
6. extract the final ZIP into a second fresh directory and rerun the same gate;
7. publish an external final verification report with exact archive size, file count and SHA-256.
