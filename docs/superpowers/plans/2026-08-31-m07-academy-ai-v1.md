# M07 Academy AI v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add a trainer-facing, provider-isolated and MCP-ready Academy AI workspace with auditable generation, explicit Apply mutations, first-class lesson text content, and aggregate student analysis.

**Architecture:** `AcademyAiRunner` executes named capabilities from `AcademyAiCapabilityRegistry` using an `AiProvider`. Every request is persisted as an `AcademyAiRun` before the capability executes. Write-capability outputs remain proposals until the trainer explicitly applies the run.

**Tech Stack:** Laravel 13, PHP 8.4, Inertia 3, React 19, Tailwind 4, Laravel HTTP client, PostgreSQL, Redis, OpenAI Responses API via HTTP.

**Spec:** `docs/superpowers/specs/2026-08-31-m07-academy-ai-v1-design.md`

## Global Constraints

- Preserve the existing Liberty/NÜM Academy core and current routes.
- Add no Composer or npm dependency.
- Preserve Coolify topology: app + PostgreSQL + Redis.
- AI writes require explicit Apply.
- Do not send student names or emails to the provider.
- Keep provider-specific code behind `AiProvider`.
- M07 remains trainer-facing; Student AI is M09.
